# Map Portfolio (Dilni Abeyrathne)

Welcome to my mapping portfolio! This is a comprehensive collection of finalized maps made for my Cartography & GIS classes at the University of Kentucky, research positions, and commissioned projects. All maps in the portfolio have been created from 2020 to the present and are continually updated with each new map I make. The portfolio webpage also contains these sections and functionalities:

- Portfolio and Research Map sections: images of all my maps, upon click a modal will pop up (exluding for the research map) with additional information and links to a high-resolution version
- Web Map and Interactive Map sections: fully interactive web maps
- About section: profile photo and a brief summary of my professional endeavors and design philosophy, alongside a link to my curriculum vitae
- Resources section: summary of webpage along with links to my GitHub, LinkedIn, and to the University of Kentucky's Mapping & GIS resources

Find my portfolio here: https://dtabeyrathne.github.io/Map-portfolio_website/
